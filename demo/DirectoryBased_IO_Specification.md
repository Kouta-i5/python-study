# DirectoryBasedFrameOptimizer 入出力仕様書

## 📥 入力仕様

### コマンドライン引数
```
FrameOptimizer.exe <input_dir> <output_dir> [options]
```

#### 必須引数
| 引数 | 型 | 説明 | 例 |
|------|-----|------|-----|
| `input_dir` | string | 入力画像ディレクトリのパス | `"C:\InputImages"` |
| `output_dir` | string | 出力画像ディレクトリのパス | `"C:\OutputImages"` |

#### オプション引数
| オプション | 型 | デフォルト | 説明 | 例 |
|------------|-----|------------|------|-----|
| `--sharpness` | double | 100.0 | 鮮明度閾値（ラプラシアンの分散） | `--sharpness 150.0` |
| `--similarity` | double | 0.85 | 類似度閾値（SSIM、0-1） | `--similarity 0.80` |

#### 実行例
```bash
# 基本実行
FrameOptimizer.exe "C:\InputImages" "C:\OutputImages"

# カスタム設定
FrameOptimizer.exe "C:\InputImages" "C:\OutputImages" --sharpness 150.0 --similarity 0.80
```

### 入力ディレクトリの要件
- **存在必須**: ディレクトリが存在しない場合はエラー
- **サポート形式**: `.jpeg`, `.jpg`, `.png`, `.bmp`, `.tiff`
- **ファイル名形式**: `still_image_1_NNNN.jpeg` (推奨)
- **読み取り権限**: プロセスに読み取り権限が必要
- **最小ファイル数**: 1個以上
- **最大ファイル数**: 制限なし（メモリ容量による）

### 2. エラー出力（stderr）
```

```

### 3. 終了コード（ExitCode）
| コード | 意味 | 説明 |
|--------|------|------|
| `0` | 成功 | 正常に処理が完了 |
| `1` | 一般エラー | 引数エラー、ファイルアクセスエラーなど |
| `2` | システムエラー | メモリ不足、権限エラーなど |

### 4. 出力ファイル

#### 出力ディレクトリ
- **自動作成**: 存在しない場合は自動作成
- **書き込み権限**: プロセスに書き込み権限が必要

#### 出力ファイル形式
```
still_image_1_0001.jpeg
still_image_1_0002.jpeg
still_image_1_0003.jpeg
...
```

#### ファイル名規則
- **プレフィックス**: `still_image_1_`
- **連番**: 4桁ゼロパディング (`0001`, `0002`, ...)
- **拡張子**: 元ファイルの拡張子を保持

## ⚠️ 注意事項

### エンコーディング
- **標準出力/エラー**: UTF-8
- **ファイルパス**: Windows標準（UTF-16）
- **ログメッセージ**: UTF-8（日本語対応）

### パス処理
- **区切り文字**: Windows標準（`\`）
- **スペース対応**: パスにスペースが含まれる場合はダブルクォートで囲む
- **相対パス**: 絶対パスに変換して処理

### エラーハンドリング
- **ディレクトリ不存在**: 入力ディレクトリが存在しない場合はエラー終了
- **権限エラー**: 読み取り/書き込み権限がない場合はエラー終了
- **画像形式エラー**: サポートされていない形式の場合は警告（処理継続）
- **空ディレクトリ**: 画像ファイルが存在しない場合はエラー終了

### パフォーマンス
- **メモリ使用量**: 画像サイズと枚数に比例
- **処理時間**: 画像数と解像度に比例
- **並列処理**: 現在は単一スレッドで処理
- **ファイルI/O**: 大量ファイルの場合、読み込み時間がボトルネック

## 💡 使用シーン

### 適している用途
- **バッチ処理**: 大量の画像ファイルを一括処理
- **定期処理**: 定期的に生成される画像の最適化
- **既存ファイル**: ディスク上に保存済みの画像の処理
- **オフライン処理**: ネットワーク接続不要の処理

### 適していない用途
- **リアルタイム処理**: カメラからのストリーミング画像
- **メモリ内処理**: メモリ上で生成・編集された画像
- **ネットワーク画像**: ダウンロードした画像の即座処理
